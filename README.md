One original one-line weather forecast for the invented city of Sleetwick, for make.fun's "Funniest Forecast for a City That Isn't" bounty: In Sleetwick, sleet until Friday, then sleet; the mayor has declared the sleet a resident, it now pays taxes. (109 characters, 109 bytes.)

## Run it

```sh
python3 main.py
```

It writes the forecast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline. Python 3.13, stdlib only, no network. Repeated runs are byte-identical.
